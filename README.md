# Portfólio Shamara Souza

Portfólio em React e TypeScript, com estética sci-fi de laboratório, projetos com links para demonstração e código, além de um minijogo de dinossauro feito em Canvas.

## Executar no computador

```bash
npm install
npm run dev
```

## Publicar na Vercel

1. Envie todos os arquivos desta pasta para um repositório GitHub chamado `portfolio`.
2. Na Vercel, clique em **New Project** e importe o repositório.
3. A Vercel reconhecerá Vite automaticamente. Clique em **Deploy**.

Não são necessárias variáveis de ambiente nem chaves de API.
